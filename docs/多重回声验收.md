# 多重回声：使用与验收

本次扩展现有单次回声，接通“扩展功能 → 高级音效”中的多重回声。保留主工作台的四阶段试听、分析与导出，不新增环境依赖。

## 操作

1. 关闭旧窗口，运行 `bash run.sh`，在基础工作台导入WAV。
2. 打开“扩展功能 → 多重回声”，勾选启用并设置次数、间隔和强度/衰减。
3. 点击“应用多重回声并返回工作台”，软件启用音效并后台处理，成功后选中音效结果。若强度原来为0，此应用按钮会初始化为0.45；要验证0强度旁路，可在主工作台设为0后点击“应用音效”。
4. 间隔和强度与主工作台05区域双向同步。多重模式启用后也可从基础工作台“开始处理”或“应用音效”生成结果。底部切换原声与音效试听，保存所选音效WAV。
5. 关闭多重模式，继续使用单次回声。选择非自定义基础预设会关闭多重模式，并把次数恢复到3；“自定义”保留当前设置。

| 参数 | 范围/默认 | 含义 |
| --- | --- | --- |
| 多重模式 | 默认关闭 | 关闭时有效次数为1，保留既有单次效果 |
| 回声次数M | 1–8，预置3 | 迟于原声的重复次数，不包含原声 |
| 间隔 | 0–1秒，默认0.30秒 | 相邻回声的时间间隔，与05区域共享 |
| 强度/衰减r | 0–0.80，默认0 | 第一次幅度为r，之后每次再乘r，与05区域共享 |

启用多重模式时同时启用音效；只勾选模式但强度仍为0时没有回声。主工作台会显示当前有效次数和最后一次延迟，处理状态显示实际采用次数。

## 原理和边界

采样延迟D=round(间隔×采样率)，输出：

```text
y[n] = x[n] + r*x[n-D] + r²*x[n-2D] + ... + r^M*x[n-MD]
```

每一项都从同一份上游信号叠加，属于有限次延迟，不用上一次整段输出反复处理。以单脉冲0.5、间隔2样本、r=0.5、M=3为例，非零值分别为0.5、0.25、0.125、0.0625。

处理顺序仍为可选去噪→可选增强→倍率→电话带通→回声→限幅。结果保持原采样率，输出样本数为倍率后样本数+M×D，最后一次完整尾音不截断。

- 强度0或音效关闭时不增加尾音。
- 间隔0时所有回声同位置叠加，倍数为1+r+...+r^M；不会增加时长。
- 不自动归一化，越界限幅并显示样本数；回声较多时可降低上游增益或回声强度。
- 单份音效float32输出仍最多128MiB，计算总尾长后在分配前检查，不能只检查第一声。输入300秒限制不变，输出允许因减速/尾音变长。
- 次数、间隔、强度变化只清除音效缓存，有效去噪/增强保留；后台参数快照包含有效次数，过期结果拒绝采用。重复应用不会累积旧回声。
- 处理和录音期间锁定扩展控件。重置保留原声/参考底噪，关闭多重模式，次数3、间隔0.30秒、强度0，两页数值框和滑块同步。
