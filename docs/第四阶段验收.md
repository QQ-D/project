# 第四阶段：声音增强验收

本阶段完成峰值归一化、音量增益、清晰度、三段均衡，以及原声/去噪/增强的图形、试听与导出切换。沿用现有 Python 环境，没有新增依赖。音效预设、播放倍率与回声留到下一阶段。

## 使用方法

1. 关闭旧窗口，运行 `bash run.sh`，导入 WAV；也可用 `bash run.sh --demo` 载入合成测试音。
2. 左侧滚动到“03 声音增强”，点击“一键增强”。按钮自动启用增强，默认直接处理原声，不需要麦克风或底噪文件。
3. 按需要调整增益、清晰度与低/中/高频，再重新处理。重复增强始终从选定的原声或去噪输入计算，不累积上一次结果。
4. 要先去噪再增强，勾选02区域“使用去噪结果作为增强输入”。有有效去噪结果时复用，没有则在同一后台任务依次计算；自动去噪不需要噪声参考，手动参考模式仍需确认底噪适用。
5. 底部切换“原声/去噪/增强”查看与试听，保存按钮导出当前阶段的 PCM16 WAV。处理结果不会覆盖原声。

## 参数和算法

| 控件 | 范围与默认值 | 作用 |
| --- | --- | --- |
| 启用增强 | 默认关闭，一键增强时打开 | 开启时“开始处理”执行增强流程 |
| 峰值归一化 | 默认勾选 | 非静音信号处理后峰值调到0.95 |
| 音量增益 | 0–2×，默认1× | 归一化之后乘以增益，保留用户音量选择 |
| 人声清晰度 | 0–100%，默认0 | 按比例叠加低频−3、中频+4、高频+2dB |
| 三段EQ | 每段−12至+12dB，默认0 | 在清晰度的倾向上额外调整 |
| 使用去噪结果 | 默认关闭 | 选择原声输入或去噪输入 |

处理顺序：三段EQ/清晰度 → 可选峰值归一化 → 用户增益 → 超过±1时限幅并统计样本数。归一化到0.95后增益0.5×，输出峰值应为0.475；不会再次归一化抵消增益。静音保持静音。关闭归一化、EQ/清晰度为0且增益1×时精确旁路。

三段采用 [W3C Audio EQ Cookbook](https://www.w3.org/TR/audio-eq-cookbook/) 的双二阶系数：300Hz低架式、1500Hz峰式（Q=1）、3000Hz高架式（架式斜率S=1），通过二阶节滤波。低采样率时各频率分别限制在采样率的0.1、0.25、0.4以内。输出保留输入长度与采样率。

清晰度是均衡参数，不代表已测得语音质量提升。归一化可能放大残留底噪；增益大于约1.05×时可能限幅，状态栏会给出实际数量。应结合真实语音试听选择参数。

## 缓存与操作一致性

- 增强参数或输入策略改变，只使增强结果失效；去噪参数改变使去噪结果失效，并清除依赖去噪的增强。直接增强原声所得结果不受无关去噪参数影响。
- 更换原声清除全部处理结果；导入失败、取消采集或后台计算失败保留已有有效数据。
- 串联计算只有全部成功且参数/输入快照仍有效，才一起采用新去噪与增强结果；过期任务不会覆盖新设置。
- 播放、右列图形和保存均使用当前选中阶段的同一缓存。左列始终保留原声。后台任务与采集互斥，关闭窗口等待后台任务收尾。
- 重置保留原声与参考底噪，恢复自动去噪60%、增强关闭、去噪输入关闭、归一化选项打开、增益1×及清晰度/EQ为0，同时同步数值框和滑块。

## 自动验证

```bash
QT_QPA_PLATFORM=offscreen .venv-run/bin/python -m pytest -q
QT_QPA_PLATFORM=offscreen .venv-run/bin/python -m scripts.verify_enhancement
```

完整测试 **163 passed，42.62秒**，包括既有128项、25项增强DSP和10项增强GUI测试。新测试先观察失败再实现，覆盖精确旁路、音调响应、归一化后增益、限幅、静音、非法设置、缓存依赖、串联原子采用、失败保留、过期快照、关闭与重置。重置滑块不同步的问题已经补充失败回归并修复。

验收脚本实际创建 Qt 主窗口，仅使用仓库的合成测试音，依次完成原声增强、勾选去噪输入、自动去噪后增强、三阶段切换、导出核对与截图。未启动麦克风或扬声器。导出采样率、长度与当前缓存一致，PCM16样本误差不超过1/32768。

本次合成验收参数：44.1kHz、6.2秒，归一化打开、增益0.75×、清晰度40%、额外EQ低−2/中+1/高−1dB。

| 去噪 | 0.21661542 |

独立只读审查未发现 Critical / Important 问题。一个 Minor 建议是把短音频/低采样率测试中的静音进一步扩展为非零脉冲；本次独立窄探针已经覆盖1至192000Hz的7种采样率、16组极端EQ/清晰度组合，共112次非零输入处理，全部有限且长度不变。

补充资源探针：48kHz、300秒合成输入，清晰度70%、EQ低−3/中+6/高+3dB、归一化打开、增益0.75×，算法单次0.275秒，进程峰值内存398.8MiB；输出14400000样本、峰值0.71249998、限幅0。此为本机单次观察，不含GUI分析，也不构成跨设备性能保证。
