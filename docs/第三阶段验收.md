# 第三阶段：谱减去噪验收

日期：2026-10-20。使用已有 `.venv-run` 和 NumPy/SciPy/PyQt5/Matplotlib，无新增依赖。

## 实现与算法

输入为不可变原声。默认自动估计背景谱，也可使用已确认的纯底噪参考。参考模式要求底噪至少0.10秒；采样率不同时只重采样参考。约32ms周期Hann窗，75%重叠，参考模式以完整有效参考帧的平均FFT功率估计噪声功率谱。

对每帧保留相位，采用功率谱减增益：

```text
alpha = 3 × 去噪强度 / 100
G = sqrt(max(1 - alpha × Pnoise / max(Pinput, 1e-20), 0.05²))
Y = G × X
```

两端补一整窗，分析/合成使用同一窗，窗平方重叠和为1.5；重建后裁回原长度。FFT每批最多256帧，不保存整段STFT矩阵。0%直接复制样本；不执行增益或峰值归一化。越界重建样本限幅并显示数量，当前验收样本无需限幅。

## 无参考自动去噪补充验收

默认勾选“自动估计底噪（直接去噪）”，只需导入原声即可处理，不采集麦克风、不导入参考、不自动确认任何选段。算法从非全零帧中选择能量最低的10%，以其平均功率谱估计背景；全零输入仍返回全零。估计谱取自身与9频点中值滤波结果的较小值，保守限制窄峰，减少连续谐波被直接当作噪声减除。后续谱减/WOLA与参考模式相同。

自动模式至少需要0.10秒原声；0%旁路可处理更短数据。估计帧可能含语音，界面明确标记“自动估计”，不会伪装成已确认的纯底噪。更适合稳定宽带背景；保护窄峰也意味着窄带嗡声可能残留，连续真人语音、音乐或非平稳噪声需要实际试听。

新增12项测试先失败后实现：已知参考质量与输入不变、无静音开头的连续谐波保留、纯音保留、数字静音补零不掩盖活动段底噪、全零、过短输入、0%旁路、只导原声的真实GUI流程、自动/参考切换和缓存失效、自动模式忽略未确认参考、后台结果的模式快照校验。数字补零问题另经失败回归复现后修复，完整128项通过。

实际Qt脚本完成“只导入原声→自动去噪→所选缓存导出并核对→截图”；未提供任何参考或启动音频设备。截图见 [自动去噪实际界面](../artifacts/自动去噪实际界面.png)，输出见 [自动合成结果](../artifacts/自动去噪_合成输出.wav)。

自动模式的同机资源检查：48kHz/300秒合成数据，3750帧用于估计，单次耗时0.760秒，进程峰值RSS463.0MiB；结果恰好14,400,000个有限样本。该记录包含Python/SciPy与输入/结果缓存，不代表所有机器的性能。

## 合成信号客观数据

固定随机种子20261020，16kHz、3秒。干净信号为440/880Hz调幅谐波，前0.4秒静音；叠加标准差0.055的白噪声。独立噪声参考2秒；GUI选段参考取加噪信号的前0.35秒。均为人工信号，不能代表真实语音的普遍效果。

| 条件 | 输入SNR | 输出SNR | 提升 |
| --- | ---: | ---: | ---: |
| 自动估计，无额外底噪，强度60% | 6.66 dB | 14.15 dB | 7.49 dB |
| 独立合成噪声参考，强度60% | 6.66 dB | 15.16 dB | 8.51 dB |
| GUI确认0–0.35秒选段，强度60% | 6.66 dB | 14.85 dB | 8.19 dB |

SNR = `10log10(sum(clean²) / sum((output-clean)²))`，包含首段纯噪声。使用已知干净参考计算，不以能量降低替代SNR；软件对无干净参考的真实录音不显示此指标。

同机一次算法资源检查：48kHz、300秒、单声道合成数据，耗时约0.594秒，进程峰值RSS约463.3MiB，结果有限且长度恰好14,400,000样本。该数字包含Python/SciPy、源缓存及结果缓存，是单次本机记录，不是跨设备性能承诺。

## 人工试听步骤

1. 关闭旧窗口，`bash run.sh --file samples/去噪测试_人工加噪.wav`。
2. 保持默认“自动估计底噪”直接去噪。若要比较参考模式，再点击“选取噪声段”，输入起点0、终点0.35；试听后勾选只有噪声并采用，会自动切到参考模式。
3. 以默认60%“一键去噪”，观察当前模式、左原声、右去噪三图及耗时。
4. 切换“原声/去噪”并播放；默认输出异常时程序会回退，仍可手动选择Generic声卡。
5. 保存去噪WAV，重导入检查声音；再改变强度，确认去噪单选禁用且需重新处理。
6. 对真实语音使用同环境底噪重复流程，以试听调整强度。稳定噪声更适合谱减；非平稳噪声和过高强度可能产生残留或音乐噪声。
