# 高级音效与中文 TTS：使用与验收

本次完成扩展页 A/B 两栏：多重回声、房间混响、机械电音、动态压缩、可排序串联、独立变调/变速，以及中文语音生成、独立试听、保存和送入主工作台。基础工作台、维纳降噪、增强、均衡和五种预设继续可用。C 栏智能模型训练、预训练模型和智能去混响仍为后续选做，入口明确禁用。

## 启动与试听音量

关闭旧窗口，在项目目录运行：

```bash
bash run.sh
```

主工作台底部和中文 TTS 栏都有“试听音量”与“静音”，两页共享，默认 100%。拖动可实时改变正在播放的设备音量，不会从头重播，不修改系统音量，也不改变缓存、图形或保存的 WAV。100% 对应音频原有电平；还需放大时，在“03 声音增强”提高增益，或启用动态压缩并调节补偿后重新处理。

## 中文生成与配音

1. 打开“扩展功能 → 中文 TTS · 离线”，输入中文，最多 400 字符。合成语速为 0.50–2.00×，默认 1.00×。
2. 点击“生成中文语音”。后台计算完成后显示采样率、时长和语速，可点“试听合成”“停止”或“保存合成 WAV”。合成不会自动播放。
3. 此时工作台旧原声保持不变。需要制作配音时，点击“送入工作台作为原声”，它会替换工作台原声，清除旧处理缓存；已有独立底噪按普通导入流程重新确认，旧原声的噪声选段会清除。
4. 在主工作台应用增强、均衡、基础预设，或在扩展页启用高级音效。处理后选择“音效”，再试听、对照六图或保存 WAV。

TTS 使用本机已有 **eSpeak NG 的 cmn 普通话语音**，固定基础音色，声音偏机械，中文自然度和多音字读音有限。当前没有多音色、云端或神经语音引擎。文字只通过标准输入送给本地隔离 Python 进程，不传至网络，无需麦克风或模型下载。

本机系统 `libespeak-ng.so.1` 与语言数据已可用，没有安装额外 Python 包。换到其他电脑时，只有相应 eSpeak NG 系统库和 cmn 数据可用才能生成；缺失时界面显示具体原因并禁用生成。单次合成超时 60 秒，输出最长 300 秒、最多 128 MiB float32 缓存；超限或失败会报告错误。

TTS 合成缓存与原声、去噪、增强、音效四阶段缓存分开。修改文字或合成语速会清除旧 TTS，需重新生成；相同输入重试失败时保留此前有效合成。后台任务期间禁止冲突操作，过期结果丢弃。TTS 试听与主工作台播放互斥；离开扩展页、开始后台处理/采集或关闭窗口会停止 TTS 试听。

## 高级音效参数

导入 WAV 或送入 TTS 后，在扩展页左栏勾选需要的模块，调节参数，滚动到底部点击“应用高级音效并返回工作台”。各模块初始关闭；勾选高级模块会启用工作台音效主开关。也可从工作台“应用音效”或“开始处理”运行同一条链路。

| 模块 | 参数与默认值 | 实际处理 |
| --- | --- | --- |
| 独立变调 / 变速 | 音高 −12 至 +12 半音，默认 0；语速 0.50–2.00×，默认 1 | 变调保持样本数，变速保持音高；同一模块内先变调再变速 |
| 房间混响 | 干湿比 0–1，默认 0.25；衰减 0.20–3.00 秒，默认 1.20 秒 | 合成早期反射与指数衰减脉冲响应，卷积后混合，保留完整尾音 |
| 机械电音 / 环形调制 | 频率 20–120 Hz，默认 40 Hz；混合 0–1，默认 0.60 | 与正弦载波相乘并按混合比例保留原声，产生频率边带 |
| 动态压缩 | 阈值 −40 至 −6 dB，默认 −18 dB；比率 1–8:1，默认 3:1；补偿 0–12 dB，默认 3 dB | 平滑 RMS 检测与增益控制，压低较响部分后补偿整体音量 |
| 多重回声 | 1–8 次，默认 3；间隔与强度继承工作台 | 第 k 次按强度的 k 次方衰减，保留最后一次尾音 |

独立音高与语速采用 NumPy/SciPy 实现的相位声码器和重采样。它与基础“播放倍率”不同：基础倍率同时改变音高和时长。要只变音高或只变语速，应把基础倍率保持 1.00×，然后启用对应独立参数。相位声码器可能使瞬态变模糊，变调也会改变音色和共振峰；当前不做说话人身份保持。

混响使用确定性的合成脉冲响应，便于重复实验；不代表真实房间的测量或物理仿真。其“衰减”设定脉冲响应时长，尾部按约 −60 dB 的包络衰减；干湿比为 0 时精确旁路。机械调制混合为 0 时同样旁路；低采样率时载波频率限制在 0.45 倍采样率以内。

## 调整串联顺序

扩展页左栏向下滚动，可看到六个节点及“上移 / 下移”。基础倍率固定先执行，之后默认顺序为：

```text
独立变调/变速 → 电话滤波 → 机械电音 → 动态压缩 → 回声 → 房间混响
```

只处理已启用的节点。选择列表项并上下移动后需重新应用。顺序会实际影响音频：例如先加回声再压缩，会让叠加部分一起参与动态检测；先压缩再加回声则不同。将变速放在回声或混响后面，也会改变这些尾音的最终时长。

所有高级参数和顺序都纳入后台快照。修改后只清除音效结果，有效的去噪/增强保留；重复应用从上游原声/去噪/增强输入重新计算。选择基础预设（“自定义”除外）或点击重置，会关闭高级模块并恢复默认顺序；“自定义”保留当前参数。

计算按真实顺序提前预测每个中间结果长度，检查最大 128 MiB float32 样本缓存；变调的伸缩中间结果也受此上限约束。它不是整个进程内存上限，卷积、FFT 和 float64 计算仍需要额外内存。全部节点完成后统一限幅至 ±1，并报告限幅样本数；过载时可降低增益、回声强度或压缩补偿。输入仍限 300 秒；减速和尾音可让输出超过 300 秒，此类长文件不能直接由当前导入器重新载入。

## 验证证据

运行命令：

```bash
QT_QPA_PLATFORM=offscreen .venv-run/bin/python -m pytest -q
QT_QPA_PLATFORM=offscreen .venv-run/bin/python -m scripts.verify_advanced_tts
```

最终完整回归 **362 项通过（87.04 秒）**：原有 248 项，加试听音量 7 项、独立变换 52 项、TTS 后端及控制器 24 项、高级 DSP 25 项、主窗口整合 6 项。实际验收发现首次生成后的进度时长仍为零，已补充失败回归并修复。一次独立整分支审查无未解决问题，80 项窄验证通过；编译、启动脚本语法、diff 空白与 88 个本地 Markdown 链接检查通过。

DSP 验证包括 440 Hz 音调在 2× 独立变速后长度减半、主频保持；±12 半音后长度不变、主频约 880/220 Hz；机械调制产生预期边带；压缩改变较响片段的增益；混响保留尾音、零湿度旁路；顺序变化影响真实样本与输出长度。中性设置、短片、静音、非零低采样率和非法/超限输入均有检查。
