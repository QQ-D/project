# 第一阶段：音频导入、分析、播放与保存 Implementation Plan

> 执行方式：在当前会话中按 superpowers:executing-plans 自行实施。用户已确认 v2 界面并明确要求开始逐步完善功能。

**Goal:** 交付能启动、导入 WAV、显示真实原声分析、播放控制和导出的 Python 桌面应用。

**Architecture:** GUI、纯音频数据/分析、播放设备分别隔离。文件读取与分析使用 Qt 后台任务，主线程只更新控件。尚未实现的 DSP、录音和选做模块置灰，避免虚构功能状态。

**Tech Stack:** Python 3.10+、已有 PyQt5 5.15、Matplotlib、NumPy、SciPy、pytest。`.venv-run` 继承 base 的现有依赖，不修改既有环境。

**Spec:** `design/界面设计说明.md`（v2，用户已确认）。

## Global Constraints

- 完全保留 design 中静态稿与说明，应用入口为 `main.py`。
- 输入转单声道，保留采样率；音频为有限值 float32，不能自动归一化原声。
- 参数和未来功能显示清楚但禁用；第一阶段没有实际去噪、增强、音效或录音。
- 音频导出 WAV PCM16，试听与保存来自相同缓存。
- 无 Git 仓库：直接在当前用户工作区开发，不创建无意义的 worktree 或提交。
- 系统缺少 PortAudio：第一阶段播放使用 PyQt5 自带 QtMultimedia，减少系统安装依赖；设备不可用时明确报错，导入/分析/导出仍可使用。

## Review Focus

- 损坏、空文件、非有限浮点 WAV：拒绝但保留已有有效音频。
- 立体声与极短音频：正确平均声道，频谱/语谱图不崩溃。
- 暂停继续和自然结束：进度一致，停止后归零，再播从头。
- 无音频设备或采样率不受支持：向用户说明，不能显示虚假播放状态。
- 连续导入与关闭窗口：禁止任务重入，不遗留正在运行的线程或音频输出。

## Task 1：真实音频数据与分析

Files: `voice_effect_lab/audio/data.py`, `voice_effect_lab/analysis.py`, `tests/test_audio.py`。

Interfaces: `AudioClip(samples: np.ndarray, sample_rate: int, name: str)`, `load_wav(path) -> AudioClip`, `save_wav(path, clip)`, `analyze(clip) -> AudioAnalysis`。最长导入 300 秒，文件体积上限 128 MiB，读取后检查时长；空数据、非有限值和超出满幅的浮点输入给可读错误。分析包含峰值保留的波形抽样、幅度频谱和 dB 语谱图。
