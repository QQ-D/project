# 第三阶段：谱减去噪 Implementation Plan

> 执行方式：superpowers:executing-plans。沿用用户已确认的 v2 设计、逐步完善及 GitHub 同步授权，在当前会话实施并最终独立审查。

**Goal:** 让已确认的底噪用于真实谱减，支持参数强度、缓存有效性、六图比较、原声/去噪试听及导出。

**Architecture:** 独立 NumPy/SciPy DSP 函数接收不可变 AudioClip，分批 STFT 功率谱减和重叠相加，返回同长度同采样率结果与处理信息。ProcessingController 管理快照、后台任务、缓存失效和阶段切换；复用现有播放器、导出和三图分析。

**Tech Stack:** 既有 Python / PyQt5 / NumPy / SciPy / Matplotlib；不安装或修改 Conda 依赖。

**Spec:** `design/界面设计说明.md` 的 B2、B5、4.2、4.4，以及已确认的分阶段实施路线。

## Global Constraints

- 原声不可变，底噪必须已确认且至少0.10秒；不同采样率的参考在算法内部重采样。
- 去噪强度0–100%，默认60%；0%精确旁路；功率谱减系数为强度比例的3倍，幅度谱底0.05。分帧约32ms、75%重叠，定批256帧控制FFT内存。
- 输出时长、采样率与原声一致，不自动增益/归一化；若重建越界，限幅并明示样本数量。
- 强度、原声、底噪或底噪确认状态变化均清除旧缓存；失败不覆盖有效数据。运行时禁止调参、采集、导入和重入。
- 试听/导出/右图指向同一有效阶段；无干净参考不显示SNR。增强/音效/TTS等保持未实现。
- 继续保留播放默认设备回退修复；自动验证不录真实麦克风，合成样本明确标注。

## Review Focus

1. 短片段与全零输入：重建不丢样、不出现NaN；Task1覆盖。
2. 底噪采样率不同：处理采样率与导出保持原声值；Task1/2覆盖。
3. 调参或底噪变更后的旧缓存：禁用去噪阶段，停止旧播放并回到原声；Task2覆盖。
4. 后台失败、关闭及过期结果：不混淆新参数和旧结果；Task2覆盖。
5. 比较图、播放与保存不一致：验证各阶段实际样本、图线和WAV；Task2覆盖。

## Task 1: 有界谱减 DSP

**Files:** 新建 `voice_effect_lab/audio/denoise.py`、`tests/test_denoise.py`。

**Interfaces:** 消费 `AudioClip`；产出 `spectral_subtract(clip, noise_clip, strength=60) -> DenoiseResult`，字段 `clip`、`elapsed_seconds`、`clipped_samples`。

- [ ] 先写失败测试：固定随机种子的谐波加白噪声，SNR至少改善3dB、基波幅度保留；0%精确相等；静音和单样本/非整帧长度；不同参考采样率；非法强度与过短参考拒绝；输入不变。
- [ ] 运行测试观察缺失算法失败，再实现STFT/WOLA谱减；以完整有效参考帧平均估计功率谱，周期Hann窗、固定重叠归一化，批处理避免整段STFT矩阵。
- [ ] 跑完整测试，记录性能/边界结果并提交。
