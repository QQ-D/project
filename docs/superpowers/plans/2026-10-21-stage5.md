# 第五阶段：倍率、预设与回声 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline, preserving the already approved v2 design, existing workspace/environment and GitHub synchronization authorization.

**Goal:** 接通五种基础音效、手动倍率/电话带通/单次回声、四阶段试听与导出。

**Architecture:** 独立 EffectsSettings/apply_effects 只消费有效上游 AudioClip。EffectsController 在同一后台任务补齐可选去噪与增强，再生成音效；全部成功且源/参数/缓存快照仍有效才采用。按实际依赖清理下游缓存，原声保持不变。

**Tech Stack:** 既有 PyQt5、NumPy、SciPy、Matplotlib，无新增依赖。

**Spec:** `design/界面设计说明.md` 4.2–4.4、5、8；已有用户确认与持续实施授权。

## Global Constraints

- 基础倍率0.50–2.00×（0.01步进），默认1；同时改变语速与音高，保持导出采样率。polyphase 抗混叠重采样，样本数 ceil(N/倍率)。
- 回声延时0–1秒默认0.30；强度0–0.80默认0。一次延迟叠加并保留尾音，延迟样本 round(delay*Fs)；0强度不加尾，0延时按(1+strength)叠加。
- 电话带通使用Butterworth N=4/SOS，低截止min(300,0.1Fs)、高截止min(3400,0.4Fs)。执行顺序倍率→电话滤波→回声→限幅统计；不隐式归一化。
- 输出缓存最多128MiB float32，分配前按输出长度检查；倍率与尾音可能使输出超过300秒，输入仍受既有300秒限制。
- 新增“启用音效”默认关闭；“应用音效”自动启用。开始处理优先执行启用的音效，其次增强，否则维持单独去噪。
- 音效输入依次由“使用去噪结果”及“启用增强”决定，不能重复套用旧音效。复用有效上游缓存，缺失时同一任务补齐；无参考时可绕过去噪运行。
- 五种风格：磁性(rate1/EQ+4,+1,−3)、娃娃音(1.35/−3,+2,+3)、大叔音(0.80/+4,0,−2)，这三种自动启用增强并将清晰度置0；保留归一化与用户增益。电话音(rate1/带通开)，山谷回声(rate1/delay.30/strength.45)，保留既有增强配置。每种预设先恢复音效的中性参数。
- “原声”预设只旁路音效（rate1/phone关/echo0），保留增强和去噪策略；“自定义”保留当前参数。点击预设加载参数，点击“应用音效”或“开始处理”运算。手动音效或增强参数更改后显示自定义。
- 更换原声清空全部处理缓存；修改增强只清除依赖增强的音效；去噪变更只清除实际依赖去噪的下游。修改去噪输入策略使后续结果失效。
- 保留既有失败数据保护、运行互斥、快照校验、关闭等待。重置恢复音效旁路及参数、同步滑块与数值框。
- 自动验收只使用仓库合成数据，不启动麦克风或扬声器，不上传私人音频。实际风格听感需用户试听，不声称身份转换。

## Review Focus

1. 倍率非整数、单样本、回声0延时/0强度不得导致空结果、无限滤波或截尾；Task1数值测试。
2. 低采样率非零输入电话滤波有限稳定；Task1覆盖1–192000Hz脉冲。
3. 处理后时长变长时，图形、播放器、进度与导出采样率/样本一致；Task2/3真实GUI验收。
4. 去噪/增强/音效依赖不同，修改或重新生成上游后不能遗留过期音效；Task2依赖矩阵与重复处理测试。
5. 末段音效计算失败或参数在任务中变化时，不能部分提交新的上游结果；Task2故障/过期快照/关闭测试。
