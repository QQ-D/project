# 基础与拓展界面整理实施计划

> 按已在对话中确认的方案执行，沿用当前目录与原有算法，不安装依赖、不读取或上传 voice/。

**目标**：基础页体现环境底噪与传统降噪；拓展页分别展示高级音效、中文TTS、智能降噪。

**设计依据**：综合实验.png 的五项基础任务和三类发挥任务，以及用户确认的三项调整。

**实现**：基础默认维纳60%，仅提供维纳/谱减；DeepFilterNet3以dbaf运行，默认100%，移入智能降噪。智能比较复用原声、固定维纳60%、独立模型结果缓存；切换方法可保留同一原声的另一模型结果，改变模型/强度只清除受影响的结果，更换原声清空全部结果。试听、六图、WAV导出与送入工作台共用所选缓存；仅公开演示具有干净参考时计算SNR。

## 验证重点

1. 改变方法不会将旧模型结果标成新方法；改变原声使全部比较失效。
2. dbaf失败时保留上一份有效结果，结束忙碌状态；模型未训练不阻塞DeepFilterNet3。
3. 更换BP模型不使有效DeepFilterNet3失效；改变DF强度不使有效BP失效。
4. 子页/主页面切换停止离开的试听；三路播放器互斥，共享音量与静音。
5. 1080×720下按钮可滚动到达，图形与导出引用同一缓存，无干净参考SNR为—。
