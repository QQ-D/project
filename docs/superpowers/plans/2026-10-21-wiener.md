# 自适应维纳降噪 Implementation Plan

> Use superpowers:executing-plans inline; continue the user-authorized improvement and GitHub synchronization workflow. Current approved app design and source/cache protection remain binding.

**Goal:** 在保留谱减的同时增加默认自适应维纳，改善当前样本的参考误差及变动背景噪声，保持人声成分。
**Architecture:** 新增独立 Wiener DSP，复用已有STFT参数、WOLA与噪声谱初始化；独立denoise_audio统一分派算法，GUI所有去噪/增强/音效链路使用同一选择与快照。干净音频只作输出评估，不进入降噪计算。
**Tech Stack:** 既有NumPy/SciPy、PyQt5，无新增依赖或模型下载。
**Spec:** 用户要求提升降噪效果；`design/界面设计说明.md`关于噪声估计、强度、缓存、后台与失败保护；下列精确行为为本次有限扩展。

## Global Constraints

- 保留spectral_subtract数值行为及0%旁路；GUI新增方法选择“自适应维纳”和“功率谱减”，默认维纳，重置恢复维纳。
- 维纳32ms周期Hann、75%重叠、每批256帧FFT、WOLA除1.5、保持长度/采样率/原声；自动至少0.10秒，0%可处理单样本。参考至少0.10秒，采样率不匹配仅重采样参考；零参考精确旁路。
- 自动噪声初始化沿用最低能量10%非零帧与9bin中值上限。逐帧SPP思想更新：固定先验SNR=10^1.5、先验存在概率.5，p=1/(1+(1+prior)*exp(-gamma*prior/(1+prior)))；pmean=.9old+.1p，超过.99时p最多.99；估计噪声p*old+(1-p)*power，平滑.8old+.2estimate。
- 最终修正：自动初始化和每8帧用31bin邻域20%谱底作条件峰值上限（高于谱底8倍时压到2倍），保护低基频密集谐波；补零边界帧和全零帧不更新噪声。参考模式使用固定已确认谱，不跟踪。
- 先验SNR xi=.98*上一帧增强功率/当前有效噪声谱+.02*max(gamma-1,0)；Wiener增益max(xi/(1+xi),.05)。强度0–60映射干湿比strength/60，60–100将噪声功率乘strength/60；强度0精确旁路。
- 不做响度归一化、不使用干净参考选帧/调参、不改变原声；输出越界统计并限幅。
- 方法选择纳入后台快照、参数互斥、全部相关缓存失效；增强与音效链路不可漏用方法。输出状态显示实际方法。
- 私人对照文件只保存在.runtime，不纳入Git；可提交合成数据、截图、代码及汇总说明。实际听感不由SNR替代。
