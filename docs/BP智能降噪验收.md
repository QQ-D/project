# 小型 BP 智能降噪：使用与验收

“拓展功能 → 智能降噪 → 小型 BP · 教学训练”已接通小型 BP 网络训练、逐轮日志、本项目模型 NPZ 保存/加载、公开加噪演示、BP 与维纳比较、独立试听、六图、保存及送入工作台。它是课程用的可解释小网络；CNN训练与智能去混响仍未接通。同一智能子页另外提供 [DeepFilterNet3](DeepFilterNet3降噪验收.md) 预训练降噪引擎。

## 快速体验

1. 关闭旧窗口，在项目目录运行 `bash run.sh`，打开“拓展功能 → 智能降噪”，选择“小型 BP · 教学训练”。
2. 点击“训练小型 BP 网络”。默认使用公开合成谐波与白色/有色噪声，20 轮、批大小 128；日志显示真实训练与验证损失。本机默认训练约半秒至一秒，无需麦克风或下载数据。
3. 也可点“加载模型 NPZ”，选择附带的 [教学 BP 模型](../artifacts/教学BP_公开合成模型.npz)，直接使用已经训练的本项目模型。
4. 点击“载入公开加噪演示（含干净参考）”，再点“运行 BP / 维纳比较”。BP 默认强度 75%，传统基线固定为自动维纳 60%。它们的强度含义不同，数值不能视为相同抑噪量。
5. 在下拉框选择“原声 / 传统维纳 / 小型 BP”，点击“试听所选”“放大查看所选六图”或“保存所选 WAV”。右侧直接显示六图，试听音量和静音与基础页、TTS同步。
6. 点击“送入主工作台作为新原声”，才会替换工作台原声，并清除旧处理缓存；随后可继续增强、均衡或制作高级音效。模型与独立训练数据保留。

处理自己的 WAV 时，先按正常流程导入原声，再打开智能降噪子页选择BP运行比较。没有干净参考时 SNR 显示“—”，可通过试听、图形与实际耗时判断；软件不会凭单份真实录音生成虚构 SNR。

## 使用自己的训练材料

“导入干净训练 WAV”接受 2–60 秒的干净单声道或可转换 WAV，不替换工作台原声。系统将原始时间序列的前 80% 用于训练、后 20% 用于验证，先分段，再各自做分析及添加独立噪声，避免相邻 STFT 帧混入训练与验证两边。

训练轮数可选 1–100，批大小 32–512。更改这些设置只改变下一次训练；已有模型在新训练成功前保留。选择“使用公开合成训练数据”可恢复默认。训练失败不覆盖旧模型与有效比较结果。

干净材料、说话人和噪声覆盖会影响泛化。默认合成谐波不是人类语料；单段干净 WAV 自动加噪也不等于充分的真实语音训练集。增加训练轮数不能保证对任意录音更好，建议保留独立测试音频比较。

## 算法与资源

网络为 **8 维输入 → 16 个 tanh 隐藏单元 → 1 个 sigmoid 输出**。输入仅来自当前含噪音频：局部峰值及邻频与谱中值底的比值、频点相对帧能量、物理频率、帧能量、前后帧局部谱特征。推理不需要干净参考。

训练标签为干净功率除以干净与噪声功率之和，即理想比值掩膜。NumPy 显式实现反向传播、软标签二元交叉熵与 Adam 更新。默认采样 24000 个训练频点和 6000 个独立验证频点；验证集不参与梯度或归一化参数拟合。默认演示使用另一个种子生成新波形与噪声，不复用训练样本。

推理采用 512 点周期 Hann 窗、128 点步长，按每批 256 帧处理，并包含特征所需的相邻帧；单批特征数组约 2.1 MiB，不展开整段的帧×频点×8 矩阵。预测掩膜与原谱按强度混合，保留原相位，再重叠相加和校正归一化。

输出保持原采样率和精确样本数，越界时统一限幅并记录数量，0% 为精确旁路。内部分析最高 16 kHz；高采样率输入会经过重采样，8 kHz 以上的内容可能损失，即使导出采样率恢复原值也不会自动恢复这些频率。低采样率、极短音频和静音都有有限值、长度检查。

输入上限为 300 秒、128 MiB float32 样本缓存；这不是整个进程的内存上限。48 kHz、300 秒、14400000 样本的公开 180 Hz 合成压力检查得到正确长度和有限数值，处理约 2.554 秒，整个探针进程峰值 RSS 约 411.5 MiB。它是单机观测，不代表所有设备的性能保证。

## 模型文件与失败保护

只接受本项目 NPZ 模型，不兼容任意 PyTorch、ONNX 或其他网络结构。权重与归一化数组在运行中只读。读取时先获取不超过 1 MiB 的不可变文件快照，再检查 ZIP 字段、总解压不超过 128 KiB、各数组 NPY 头、形状、类型、版本和有限数值，然后使用 `allow_pickle=False` 加载。

损坏压缩数据、对象数组、过大成员、异常形状、NaN/Inf、未知版本均报错，加载失败保留旧模型和有效结果。保存的只是数值参数及简短训练来源标签，不包含训练音频或执行对象。

智能比较与原声/去噪/增强/音效四阶段分开缓存。更换原声清除全部旧比较；更换BP模型或强度只清除BP结果及指标，同源DeepFilterNet3结果与传统基线保留。切换模型不会清除有效结果。独立模型与训练数据保留。后台结果核对输入和模型身份及参数修订号，过期结果不采用；传统/BP计算和三份分析全部成功后才一起采用。

三路播放器（主工作台、TTS、智能比较）互斥，共用音量、静音和输出选择。开始后台任务/采集、切换拓展子页、离开拓展页、更换设备或关闭窗口会停止相应预览。训练中关闭窗口会等后台任务收尾。

## 真实验收结果

命令：

```bash
QT_QPA_PLATFORM=offscreen .venv-run/bin/python -m pytest -q
QT_QPA_PLATFORM=offscreen .venv-run/bin/python -m scripts.verify_neural
```

20 轮、批大小 128 的实际训练日志：训练 BCE 从 **0.093123 降至 0.078059**，独立验证 BCE 从 **0.118682 降至 0.107566**。损失会逐轮波动，并非单调下降；当前使用最后一轮权重。

独立演示为种子 20261022 生成的 3 秒谐波/白噪声，16 kHz、48000 样本：

| 方法 | SNR | 相对输入改善 |
| --- | ---: | ---: |
| 原加噪输入 | 5.0000 dB | — |
| 自动维纳 60% | 13.9076 dB | 8.9077 dB |
| 教学 BP 75% | 13.9085 dB | 8.9085 dB |

**该样本上两者表现接近，不能据此宣称 BP 更好。** 单个合成谐波/噪声结果不能代表真实语音、非平稳噪声、可懂度或听感。耗时为实际测量，详情随每次运行更新在 JSON 中。

验收还完成：训练不替换原声；模型保存/重载后权重及推理相同；原声/传统/BP 三份结果的播放缓存、六图与导出一致；PCM16 误差不超过 1/32768；换成无参考原声后全部 SNR 为 None；明确送入 BP 结果后继续增强与 0.2 秒混响，输出 51199 样本。1080×720下智能子页的训练/发送均可滚动到达，TTS 发送按钮仍完整可见。

初次完整回归暴露对比窗口延迟销毁时的 Qt 生命周期崩溃，缩小到组合测试可复现；将捕获父/子对象的 `destroyed` 回调改为对象绑定的 `finished` 槽，关闭时立即释放控制器引用，补充“关闭→立即重开→延迟删除/GC”失败回归后通过。原先崩溃的组合测试 25 项通过。最终完整结果见[开发进度](开发进度.md)。
