## 智能降噪操作

1. 在基础页导入原声，打开“拓展功能 → 智能降噪”。
2. 默认模型为DeepFilterNet3，混合100%，无需训练或底噪参考。点击“运行 DeepFilterNet3 / 维纳比较”。模型仍由已有dbaf环境在CPU两线程运行。
3. 模型切换为“小型 BP · 教学训练”时，才显示干净训练WAV、轮数、批大小、训练日志、NPZ保存/加载和BP强度。默认20轮、批大小128、强度75%；模型训练或加载成功后才能比较。
4. 下拉框统一选择原声、传统维纳60%、DeepFilterNet3、小型BP；尚未生成的结果不可选择。两种模型需各自运行一次，可同时保留同一原声的两份模型结果。
5. 右侧直接显示原声与所选结果的六图；也可放大查看、试听或保存所选WAV。图形、播放器与导出引用同一份缓存。三处试听音量和静音同步。
6. 点击“送入主工作台作为新原声”，才替换工作台原声及旧处理缓存；之后可做增强或音效。默认不再额外勾选传统去噪，避免无意重复处理。

DeepFilterNet3的百分比是原声/模型输出的混合，BP百分比是频谱掩膜应用强度，维纳60%是固定传统基线；相同数字不代表相同抑噪量。没有干净参考时只显示真实耗时，SNR为“—”。公开加噪演示有已知干净参考，才计算SNR；普通导入文件即使与演示数值相同，也不会自动关联参考。

## 缓存与错误恢复

- 基础四阶段与智能比较分开存储。运行智能比较不覆盖基础原声或去噪/增强/音效结果。
- 切换模型不清除同源结果；修改BP强度或更换BP模型，仅清除BP结果及对应指标；修改DeepFilterNet3混合仅清除该模型结果及指标。
- 替换原声会清除所有比较结果和干净参考关联；独立训练数据与BP模型保留。
- 后台检查原声、模型、方法、强度与修订号；期间发生变更的结果不采用。作业失败保留上一份仍有效的比较，不自动换算法。
- 切换拓展子页、离开拓展页、开始任务/采集、更换输出设备或关闭窗口会停止相应预览；三路播放器互斥。
