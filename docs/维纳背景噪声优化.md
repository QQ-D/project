# 维纳背景残留优化与开源对照

2026-10-22。针对用户反馈“处理后嘶声、风扇背景仍明显”，改进基础页自适应维纳，默认仍为60%。这次优化重点是降噪质量。

## 已确认的问题及改法

旧实现对噪声谱的窄峰反复施加谐波保护。它能保护连续人声，但也会把稳定风扇嗡声的噪声谱压低，滤波器误以为这些频率噪声很少，因而残留明显。

现在从非数字零帧中最低能量10%估计原始背景谱。在整帧能量存在明显变化、估计谱有宽带成分时，再看各频点是否随时间近似稳定。只为这些频点保留原始估计的一部分，避免真正的稳定背景峰被反复压低；随轻声/正常发声改变的谐波仍受保护。

具体工程设置：全局能量90/10分位比大于6；谐波保护后剩余谱能量超过原始10%；最多128个时间位置，每个平均16帧，逐频点90/10分位比不超过6时才允许50%原始谱保留。保留量同时受平滑观测功率两倍限制，背景消失后可下降。快速DD响应需要后验功率SNR大于10，且整帧超过25%频点满足该条件；否则保持原来的0.98平滑，减少停顿处噪声触发快速响应。

这些阈值是工程启发式，不保证所选低能量帧完全没有人声。32ms窗、75%重叠、分批FFT、原相位、原采样率和精确长度保持；强度0和全零参考仍精确旁路，谱减算法不变。维纳变化自动用于基础去噪、后续增强/音效及智能页传统基线。

## 36组独立对照

参数探索后换用两段新的自写中文TTS、两个独立种子42031/90557，测试三类噪声和0/5/10dB三档输入，共36组。未添加“前半秒一定为噪声”的假设。干净参考只参与评估；降噪只接收含噪音频。溢出风险时，输入、噪声和干净参考共用一个缩放系数，不裁掉噪声峰，也不把输出归一化。

每类12组的平均值，数值越高表示停顿噪声衰减或参考SNR越好；投影是幅度保留指标，不是可懂度评分：

| 背景类型 | 停顿处噪声衰减 dB：旧→新 | 输出参考SNR dB：旧→新 | 人声投影：旧→新 |
| --- | --- | --- | --- |
| 模拟风扇：低通随机噪声＋93/186Hz嗡声 | 2.81 → 13.60 | 6.40 → 8.86 | 0.88 → 0.89 |
| 嘶声：600Hz高通随机噪声 | 10.71 → 11.34 | 10.97 → 11.13 | 0.95 → 0.95 |
| 中途幅度增大的宽带噪声 | 20.14 → 20.14 | 11.59 → 11.55 | 0.90 → 0.90 |

最终版本对风扇类改善较明显；嘶声改善较小。突增宽带噪声总体与原版接近，少数样本参考SNR略有退步。数据同时保留逐例SNR、SI-SDR、人声投影、停顿衰减和耗时，不挑选最好一条作为整体结论。新版本增加少量分析开销，单例耗时均值约0.05秒，未将其称为运行速度提升。全部结果来自公开合成普通话及程序噪声，不能直接推广到真人录音、自然度或可懂度。

## 回归、审查与使用

公开中文的风扇/嘶声4项参数化回归在旧版观察到3失败1通过；改进后全部通过。另覆盖无噪声纯谐波轻声、含宽带气声轻声和风扇停止后的弱人声。一次独立审查复现后两种误抑制，均先补失败回归再修复，保留人声保护优先于只追求更安静的指标。

最终完整回归 **468项通过（134.30秒）**，无测试警告。94个Python文件语法、run.sh语法、diff空白和183个本地Markdown链接检查通过。实际Qt验收已执行维纳→谱减切换、WAV导出核对、维纳串联增强/音效、智能页传统/DF3/BP同源比较。图形、播放器与导出使用相同缓存，没有启动真实麦克风或扬声器，也没有读取用户voice目录。

关闭旧窗口后重新运行 `bash run.sh`，基础页导入音频，保持自动估计、维纳60%，点击一键去噪。仍有明显残留可逐步提高强度；噪声复杂时可使用已接入的DeepFilterNet3，或以确认过的纯底噪改善参考估计。持续纯窄带声和无停顿语音可能仍会保守保留，语音和噪声同频时无法保证无损分离。
