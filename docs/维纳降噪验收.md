# 自适应维纳降噪：原理、使用与验收

本次在保留原谱减的基础上增加自适应维纳，作为默认去噪方法。无需下载模型、安装新依赖或提供干净语音；自动模式仍只需要待处理WAV。干净参考只用于离线评估，不进入降噪计算。

## 使用

1. 关闭旧窗口，运行 `bash run.sh`，导入待处理WAV。
2. 02区域“去噪方法”保持“自适应维纳（默认）”，自动估计打开，从60%开始“一键去噪”。
3. 切换“原声/去噪”试听。需要对照时选择“功率谱减”，重新处理；方法切换会清除依赖旧去噪结果的缓存。
4. 可以调整强度后重算。100%更强，也可能削弱弱辅音或使声音发闷；不保证强度越大越好。
5. 勾选“使用去噪结果作为后续处理输入”后，增强和音效使用所选去噪算法，缺少缓存时在同一任务中补齐。保存与试听使用当前阶段同一份样本。
6. 使用已确认的独立底噪时，两种算法都支持；参考模式的维纳使用固定参考谱，自动模式才跟踪背景变化。重置恢复默认维纳、60%和自动模式。

## 与原谱减的差别

原谱减用固定背景谱直接从每帧功率中扣除噪声。新版使用平滑估计的信号/噪声比计算维纳增益，自动模式还会更新噪声谱。决策导向估计参考 [Ephraim与Malah的论文](https://malah.net.technion.ac.il/files/2017/08/Ephraim_Speech_Enhancement_ASSP84.pdf)；软语音存在概率的噪声估计思想参考 [Gerkmann与Hendriks的研究介绍](https://www.inf.uni-hamburg.de/en/inst/ab/sp/publications/taslp12noisepsd.%20html)。

本实现有自己的初始化、窄峰保护和强度映射，并非原论文的完整复现，也不是神经网络降噪：

- 32ms周期Hann窗、75%重叠，最多256帧一批FFT，WOLA重建后裁回原长；保持输入采样率与原声。
- 自动模式仍从非全零帧中最低能量10%初始化背景谱，并用9频点中值上限降低持续谐波被误当底噪的风险。初始化帧可能含人声。
- 逐帧估计各频点的软语音存在概率，低概率时更多采用当前功率更新背景，高概率时更多保留旧估计。补入边界的零帧和全零帧不参与跟踪。
- 在初始化及每8帧更新后计算31频点邻域的20%分位谱底，只对超过谱底8倍的明显峰值压到最多2倍谱底。原来的9频点保护对密集低基频谐波不足，独立审查复现后已用80/120Hz七次谐波、12秒持续信号补充失败回归并修复。条件限制避免把有色背景的平滑谱包络整体压低。
- 先验SNR使用0.98的上一帧增强功率与0.02的当前估计相加；增益为xi/(1+xi)，下限0.05，保留含噪相位。
- 强度0精确旁路；0–60%按干湿比渐入，60%应用完整基础滤波；60–100%增加有效噪声功率系数。新版的强度映射与谱减不同，跨算法应试听比较。
- 不做响度或峰值归一化；越界限幅并统计数量。零参考精确旁路，静音保持静音。

它更适合相对连续的背景与一定程度的噪声变化。持续窄带嗡声可能受保护而残留；复杂人群声、音乐以及弱语音与噪声重叠仍可能误判。背景更安静并不等于语音更自然。

## 验证方法

```bash
QT_QPA_PLATFORM=offscreen .venv-run/bin/python -m pytest -q
QT_QPA_PLATFORM=offscreen .venv-run/bin/python -m scripts.verify_wiener
```

最终完整回归 **229 passed（70.65秒）**，在原227项基础上新增2项低基频保护测试。新增25项DSP测试与5项GUI测试均先观察缺失功能失败，再实现通过。DSP测试使用独立随机种子，覆盖稳定白噪声、有色噪声、后半段突然增大的噪声、持续纯音保护、数字补零、静音、零参考边界、异采样率参考、强度0/低强度混合、非法值和方法分派。合成参考SNR改善同时约束人声投影，避免把整体静音当成去噪。

GUI测试覆盖默认维纳/重置、标签与实际输出、切换方法清理所有依赖缓存而保留独立原声增强、旧方法后台结果拒绝、串联方法选择一致。现有失败保护、关闭等待及四阶段流程继续由全套测试检查。

真实Qt验收脚本仅使用仓库合成数据：默认维纳处理→切换谱减并重新处理→逐样本核对导出→维纳串联增强和音效→切回去噪截图。无麦克风或扬声器启动，所选缓存与播放数据、图形和PCM16导出一致。

本次仓库合成样本输入SNR 6.66dB，同一自动60%设置下谱减输出14.15dB，维纳输出22.25dB。此样本为稳定白噪声加窄带谐波，容易处理，不能据此承诺真人录音的改善幅度。

输入仍受300秒、128MiB文件限制，自动至少0.10秒（0%旁路除外）；参考至少0.10秒。短音频与低采样率有数值测试。独立参考只在内部重采样，不改变原声。所有处理继续在后台执行，运行中禁用方法切换和调参；程序化参数变化仍由快照校验拒绝旧结果。

## 独立审查与修复

独立只读审查发现1项Important：80Hz密集谐波持续发声时，原9频点保护仍逐渐将其吞入噪声。已先用80/120Hz七次谐波复现2项失败，再改为宽邻域条件峰值限制，25项DSP测试通过，最终完整229项回归通过；持续信号保持与噪声突增抑制均受回归约束。

Minor后续测试建议：现有低采样率非零脉冲用全零参考，属于旁路覆盖；尚可补充非零参考下的完整滤波自动回归。独立100Hz自动非零探针正常，当前未发现该路径缺陷。

审查未访问私人录音、实体音频设备或重复全套测试。真人改善、自然度与实际设备仍由本机对照和人工试听确认，审查不代替这部分验收。
