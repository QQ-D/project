# 智能人声音效台

[GitHub 仓库](https://github.com/QQ-D/project)

数字信号处理综合实验，Python 桌面版。界面按已确认的 [v2 设计](design/界面设计说明.md) 逐步实现。

## 当前已实现：第二阶段

- 麦克风录音、结束、取消，输入设备与目标采样率选择；实际格式以设备为准，结束后进入真实分析、试听和保存。
- 环境底噪独立采集，约 1.5 秒自动停止，不覆盖原声。
- 波形拖选或数值选择纯噪声片段，支持试听；至少 0.10 秒，需显式确认没有人声。
- 底噪来源、时长、采样率与确认状态管理，支持确认沿用和清除。
- WAV 导入，显示真实采样率、时长及源声道数；立体声转单声道。
- 同一原声缓存的真实波形、幅度频谱、语谱图。频谱分析最多取前 8 秒，图标题显示实际时长；语谱图覆盖整段，长音频均匀抽帧显示。
- 输出设备选择，原声播放、暂停、继续、停止、进度、末尾重播；设备不可用时显示明确错误。
- 原声保存为 PCM16 WAV，保持音量，不做隐式归一化。
- 后台导入/分析与保存；损坏文件不覆盖已有原声；文件任务结束后安全关闭窗口。

**尚未实现**：谱减去噪、人声增强、均衡、音效预设及全部选做算法。界面保留入口并置灰；右列图形保持待实现状态，不显示虚构处理结果。

## 运行

已盘点本机环境，选择 Conda base 的 Python 3.13.5 + 已有 PyQt5、Matplotlib、NumPy、SciPy。详见 [环境检查](docs/环境检查.md)。没有修改 base 或其他既有环境。

当前项目已经创建 `.venv-run`，可以直接启动：

```bash
bash run.sh
```

先用附带合成测试音体验导入与分析：

```bash
bash run.sh --demo
```

也可指定自己的文件：

```bash
bash run.sh --file /绝对路径/录音.wav
```

如果 `.venv-run` 不存在，本机可通过以下方式重建，复用 base 包：

```bash
/home/rwj/anaconda3/bin/python -m venv --system-site-packages .venv-run
```

在其他电脑上建议用 Python 3.11 或更新版本创建独立虚拟环境，再安装 `requirements.txt`；固定版本记录的是本机验证组合。Linux 还需桌面 Qt 所依赖的图形和音频系统库、可用音频输出设备，以及中文字体。字体优先 Noto Sans CJK；Windows 可使用微软雅黑。

## 录音与底噪流程

1. 选择输入设备和目标采样率。支持 16、44.1、48 kHz；目标采样率不受支持时使用设备支持的实际 PCM 格式，元信息显示实际值。
2. 本机默认 ALSA 输入可能不可用，建议选择 `plughw:CARD=Generic,DEV=0`。已只读确认它支持上述三种采样率的单声道 PCM16，未自动采集麦克风内容。
3. 点击“采集底噪”，保持安静，约 1.5 秒后自动结束；也可以手动结束或取消。底噪与原声分别保存在内存中。
4. 点击“开始录音”再说话，点击“结束录音”结束；底部固定的“结束录音”也可使用。最长 300 秒，原始采集缓冲区上限 128 MiB。录音中不能同时导入、保存、播放或再次采集。
5. 结束后后台分析，成功后替换原声；空录音、取消和设备错误均保留已有有效原声及底噪。关闭窗口会取消未完成采集，不自动保存录音。
6. 选择输出设备后试听，并按需要保存原声 WAV。

## 从已有音频选择底噪

1. 先导入或录制音频，点击“选取噪声段”。
2. 在波形上拖动选区，或输入起止时间；可点击“试听选段”和“停止试听”。
3. 确认该区间只有环境底噪、没有说话声后勾选确认框，再点击“采用选段”。更改区间会撤销旧确认。原声不会被裁剪。
4. 换成新的原声后，来自旧原声的选段会清除。独立麦克风底噪在导入新文件后标为待确认；同一输入设备继续录音可沿用已确认底噪。
5. 更换输入设备后，底噪也会标为待确认；确认环境一致后点“确认沿用底噪”，否则重新采集或清除。

当前底噪缓存只是为下一阶段准备，尚未运行谱减，不会改变原声。

## 文件导入与试听流程

1. 导入 WAV，或点击右上“载入合成测试音”。合成测试音由多个音调与少量噪声构成，**不是真人语音，也不作为去噪效果证据**。
2. 检查左侧元信息与右侧原声三幅图。
3. 选择输出设备后播放；暂停后点击继续；停止将进度归零。本机默认 ALSA 输出不能打开时，选择 `plughw:CARD=Generic,DEV=0`（已通过静音设备验证）。
4. 点击“保存原声 WAV”，导出当前缓存。源音频不会自动归一化或套用任何灰色控件效果。

当前版本输入上限为 300 秒、128 MiB；支持常见整数 PCM、浮点 WAV。空文件、NaN/Inf 和超出 ±1 的浮点幅度会报错。读取立体声后逐帧平均声道。PCM16 导出存在正常的量化误差，不是字节级复制原 WAV。

设备不支持源采样率或单声道 PCM16 时，播放器按 Qt 返回的设备支持格式重采样/调整输出声道；此转换仅用于播放，不改变原声缓存或导出采样率。沙箱内枚举不到设备；在桌面权限下已找到输入/输出设备，且 Generic 声卡通过全零静音的播放、暂停、继续和自然结束验证。默认 ALSA 设备在本次验证中无法打开，需要显式选择 Generic。静音状态验证不能替代真实语音的听感检查。
